# TradeWise

Trading education and paper-trading web application, primarily for Indian markets.

## Shared project documents
- [AGENTS.md](./AGENTS.md) — project knowledge, architecture, module dependencies and agent workflow.
- [frontend/DESIGN.md](./frontend/DESIGN.md) — shared visual identity and frontend conventions.
- [docs/TESTING.md](./docs/TESTING.md) — testing plan, execution log and agent remarks.

Read `AGENTS.md` before work. Frontend agents must also read `frontend/DESIGN.md`. Update `docs/TESTING.md` when behavior or test coverage changes.

## Stack
React + Vite; Node.js + Express; Prisma; PostgreSQL; REST APIs. Supabase is prohibited.

## Scope
This starter pack creates documentation and the intended component directory structure. It does not implement the application, install dependencies, or claim tests have passed.
